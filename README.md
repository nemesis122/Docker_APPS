# Docker Luncher APP

DSM launcher for container web applications with a shared NAS app list and read-only live monitoring.

The screenshot contains fictional demonstration data only.

Version 1.4.1 reduces tile dimensions in all three sizes, with smaller icons and tighter spacing. Bold text remains at least 12px.

Features: container import, CPU/RAM monitoring, temperature, network rates, volume usage bars, adjustable tiles, light/dark themes, German/English, JSON import/export and an offline icon library.

Shared app list: docker/Docker APPS. Intended for DSM 7.2+ with File Station and appropriate permissions. Preview build tested locally with simulated DSM responses; no root installation privileges and no container control.

Icons: selfh.st/icons (CC BY 4.0), plus attributed additional logos. Detailed credits are bundled in the package.
